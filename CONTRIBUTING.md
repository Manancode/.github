# Contributing

Thanks for wanting to contribute. This file is the default for every repo in this account that doesn't ship its own CONTRIBUTING.

## Getting started

1. Fork the repo and branch off `main`.
2. Install the project's dependencies.
3. Run the tests (and lint) before opening a PR.

## Pull requests

- Keep changes focused. One thing per PR.
- Add or update tests when behavior changes.
- Update the docs when setup, usage, or architecture changes.
- Write commit messages in the imperative mood ("add gate X"), not "added gate X".

## Issues

Open an issue for bugs and feature requests. Say what you expected, what happened, and how to reproduce it. For questions, open an issue or a discussion and we'll point you the right way.

## Code of conduct

By contributing you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
