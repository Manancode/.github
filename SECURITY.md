# Security Policy

If you find a security vulnerability, please report it privately so we can fix it before it becomes public.

## Reporting a vulnerability

Do not open a public GitHub issue for security problems.

Instead, use the private security advisory form on the affected repo (Security -> Report a vulnerability), or email the maintainer directly.

Include:

- a description of the vulnerability
- steps to reproduce it
- the affected project and version
- any suggested fix

## Response

We aim to acknowledge reports quickly and will keep you updated as we work on a fix. Credit will be given with your permission.
